# Domain expert checklist

- [ ] Check primary source identity, DOI, authors, dates and source conflicts.
- [ ] Review the randomly selected evidence locations, entailment and interpretation.
- [ ] Review ten subquestions and missing method/application families.
- [ ] Check gap scope, known approaches and potential counterexamples.
- [ ] Attempt to invalidate each novelty candidate, including the weak OMP control.
- [ ] Review severe model/evidence disagreements explicitly.
- [ ] Check coherent-channel, sampling, fixed-point, memory and deadline assumptions.
- [ ] Inspect baselines, ablations, statistics, failure and acceptance criteria.
- [ ] Record reviewer identity, date and evidence before requesting any SRL advancement.

No checkbox is automatically completed.
