# ADR 0005: Own search, metadata, citation and full-text ports

Status: accepted. Compliant fixed-origin HTTP adapters implement scientific source ports.
Crossref/OpenAlex are practical initial implementations; arXiv and optional authenticated IEEE
fit the same boundary. Local full text is workspace-contained. Search completion and coverage
are operational records, not assertions a model can invent. Ranked located chunks supply bounded
reader context. External text stays untrusted data. An evidence framework can be wrapped later
without owning Research Council's claims, gaps, novelty or gates.
